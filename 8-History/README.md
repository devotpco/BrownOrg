# 8-History

**0.1** This folder holds records of the project's document history.

**0.2** The Library is the shared set of notes on rules and formats that the project points at. Its `Method/Folder_Structure.md` sets out this folder's place in the project's layout. `0-AImemory/RULES.md` says where the Library is.

## 1. Sub-folders

**1.1** `Revision/` holds the revision history of each document: one file per document, named after the document.

**1.2** `Archive/` holds documents that have been replaced or withdrawn.

**1.3** `Errata/` holds errata documents, which record errors found in documents.
