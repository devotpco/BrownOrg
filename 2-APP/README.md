# 2-APP

**0.1** This folder holds the application code: code that people write. In this README, "the app" means the application.

**0.2** The Library is the shared set of notes on rules and formats that the project points at. Its `Method/Folder_Structure.md` sets out this folder's place in the project's layout. `0-AImemory/RULES.md` says where the Library is.

**0.3** `Method/Folder_Structure.md` calls such code software 1.0, and defines the term under "Terms".

## 1. Sub-folders

**1.1** The usual folders for the app's kind go here, for example `html/` and `css/`, named for two file types that web pages are written in.

**1.2** `Data/`, `Boundary/` and `Business/` each hold a README that says what the folder is for. In brief, they hold the app's data, its external connections, and its business logic.
