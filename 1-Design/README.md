# 1-Design

**0.1** This folder holds the project's design documents.

**0.2** The Library is the shared set of notes on rules and formats that the project points at. Its `Method/Folder_Structure.md` sets out this folder's place in the project's layout. `0-AImemory/RULES.md` says where the Library is.

## 1. Sub-folders

**1.1** `Draft/` holds working drafts.

**1.2** `Locked/` holds designs that are settled. A file there is called locked. The rule for changing a locked file is stated in the Library's `Method/Folder_Structure.md`, under the entry for `1-Design`. Read that rule before changing any file in `Locked/`.
