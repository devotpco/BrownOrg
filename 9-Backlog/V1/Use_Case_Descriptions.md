# Use Case Descriptions

**0.1 What.** By version V1, each use case gets a formal written description. Its header gives the goal, the stakeholders and their requirements, the prerequisites (preconditions) and similar items. Its body gives the main success scenario (the most robust happy path) as numbered steps. Alternate scenarios cover options and error recovery.

**1.1 Why it waits.** It is out of v0's scope. v0 is kept simple.

**2.1 What unblocks it.** The start of V1.

**3.1 Plan.** This is a known pattern, not to be reinvented. The known source is Alistair Cockburn's "fully dressed" use case template, in his book Writing Effective Use Cases (Addison-Wesley, 2000). This citation is to be checked when V1 starts.

**3.2 At V1 start.** The analyst verifies the template against its source. The archivist writes it as a Library Reference note. Use cases then follow that note.
