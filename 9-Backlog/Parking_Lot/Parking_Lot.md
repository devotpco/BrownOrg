# Parking Lot

**0.1** This file is the parking lot of the project BrownOrg. The parking lot holds items that belong to the project but are not being worked now. An item may be a change waiting on a locked file, an open question for the Steward, or a component that has been stated but not designed.

**0.2** The Steward is the human who holds the decision on the project. A locked file is a settled design that only the Steward may approve an edit to. The project manager keeps this file. The Library notes `Method/Cross_Functional_Team.md` and `Method/Folder_Structure.md` define these terms and roles. The Library is the folder `/Users/jerry/DEV/DEVLibrary/`, which holds rules and formats that any project may reuse.

**0.3** Each item names what it is, why it waits, and what unblocks it. An open question for the Steward also names the work that may drift off course while the question stays open.

**0.4** An item leaves this file when it is done, or when it moves into the backlog. The backlog is the folder `9-Backlog/`. It holds work scoped out of the current version, in one sub-folder per version.

**0.5** Each open question carries its own number, as entry P-3 of the policy binder, `0-AImemory/BINDER.md`, records. The Library note `Style/Outline_Numbering.md` §5.3 says how another document cites a question.
